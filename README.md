# INTEGRATING SOFT ACTOR-CRITIC WITH QUALITY-DIVERSITY FOR HIGH-DIMENSIONAL CONTINUOUS CONTROL

Thai Huy Nguyen, Phuc Bui Dang

This is the JAX implementation built upon QDax library for the final project of CS2311.CH190 courses. 

## Quick start

You can immediately start running any methods (ours and baselines) by going to the quick-start folder and run your desired notebook

The notebook will immediately install all necessary packages, modify the code (for DCRL-ME SAC) and run the code.

## Code

If you are interested in our implementation of DCSAC-ME framework, you can go to the qdax/core/emitters/dcrl_sac_emitter.py and qdax/core/neuroevolution/losses/sac_loss.py files, which are our main modifications of the QDax library
